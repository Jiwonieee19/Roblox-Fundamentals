# RobloxFundamentals
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0.

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "RobloxFundamentals.rbxlx"
```

Next, open `RobloxFundamentals.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
